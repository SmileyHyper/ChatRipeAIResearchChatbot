# Transformer Models

The Transformer is a deep learning architecture introduced in the paper "Attention Is All You Need" (2017). It is based on the multi-head attention mechanism.

## Key Concepts
- **Self-Attention**: Allows the model to weigh the importance of different parts of the input.
- **Positional Encoding**: Since Transformers have no recurrence or convolution, positional encodings are added to the input embeddings to provide information about the order of sequence.
