# Bibliography Template

A standardized template for managing academic references.

## Fields
- **Title**
- **Authors**
- **Year**
- **Publisher/Journal**
- **DOI/URL**
- **Notes/Annotations**

## Tools
- **Zotero**: Reference management and bibliography generation.
- **Obsidian Citations**: Link PDFs to notes.
